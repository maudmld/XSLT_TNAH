# XSLT_TNAH
Devoir prévu dans le cadre du cours d'XSLT du master 2 TNAH. Le dossier contient trois fichiers (xml, xsl, css) ainsi qu'un dossier de sortie contenant les fichiers HTML qui composent le résultat de sortie de la transformation. 
Note sur l'usage de l'IA générative : comme indiqué en en-tête du fichier .css, le CSS du document a été généré partiellement à l'aide de Claude Sonnet 4.6.
